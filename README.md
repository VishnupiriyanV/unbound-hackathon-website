# UNBOUND '26 Hackathon Website

The official landing page for **UNBOUND '26**, the first edition online hackathon organized by **FOSS CLUB PONDICHERRY UNIVERSITY**.

## Design Philosophy
Built using a **Neoclassical** aesthetic featuring elegant serif typography, custom double borders, and gold accents. Dark mode is default, with dynamic toggle support for a light cream mode.


## Local Development
To run this static website locally, serve the root directory:
```bash
python -m http.server 8000
```
Then open your browser and navigate to: [http://localhost:8000/](http://localhost:8000/)
